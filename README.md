# Domain & SSL Certificate Expiry Alert System

## 📌 Project Description

The Domain & SSL Certificate Expiry Alert System is an IT operations tool that monitors domain registration and SSL/TLS certificate expiry dates.

The system performs daily checks and sends alerts before a domain or certificate expires.

## 🎯 Objectives

- Monitor domain expiry dates
- Monitor SSL/TLS certificate expiry dates
- Send alerts before expiry
- Escalate critical alerts to the Security Officer
- Maintain alert and scan logs
- Provide compliance reports

## 🔔 Alert Levels

- **30 Days:** Warning Alert
- **15 Days:** High Alert
- **3 Days:** Critical Alert

## 👥 Users

- **SysAdmin**
- **Security Officer**

## ⚙️ Main Functions

1. Perform WHOIS lookup
2. Perform SSL/TLS certificate check
3. Calculate expiry dates
4. Generate expiry alerts
5. Send notifications
6. Escalate critical alerts
7. Acknowledge alerts
8. Generate compliance reports
